Flagship: vllm-learning Curriculum

14 progressive stages spanning 4 tracks from mathematical foundations to production engine mastery.

Track 1: Foundations & Core Execution Stages 00–03
00

Systems Foundations

Linux systems, process/thread models, memory hierarchies (registers, caches, DRAM), and OS paging.

01

Deep Learning Execution & Tensors

PyTorch runtime internals, tensor layouts, strides, PCIe vs. HBM transfer bottlenecks, and pinned memory.

02

Transformer Inference Mechanics

Autoregressive loop, causal masking, MHA/MQA/GQA, token projection FLOPs, and logit sampling.

03

Prefill vs Decode & KV Cache Bottleneck

Compute vs. bandwidth asymmetry, footprint equations, and internal vs. external memory fragmentation.

Track 2: Architecture Solutions & Hardware Grounding Stages 04–06
04

PagedAttention & Virtual Memory

Operating system paging analogy, logical to physical blocks, non-contiguous allocation, and zero waste.

05

Continuous Batching & Scheduling

Static vs cellular vs iteration-level batching, preemptions, recomputation vs swap, and prompt prioritization.

06

GPU Architecture & CUDA

Streaming Multiprocessors (SMs), warps, shared memory bank conflicts, and CUDA execution graphs.

Track 3: Kernels & Engine Internals Stages 07–09
07

Attention Kernels & Tiling

FlashAttention online softmax, SRAM tiling, fused operators, and IO-aware complexity.

08

Inference Engine Architecture

API ingress, request state, execution loop, model runner, samplers, and token streaming pipeline.

09

vLLM Production Mastery

Upstream code tracing of V0 vs V1 engines, worker architectures, custom ops, and test suites.

Track 4: Scale, Serving & Research Stages 10–13
10

Distributed Inference & Communications

Tensor parallelism, all-reduce collective communication, pipeline bubbles, and expert parallelism.

11

Advanced Serving & Quantization

Chunked prefill, speculative decoding, disaggregated serving, FP8/AWQ/GPTQ weight quantization.

12

Performance Engineering

Nsight Systems, Nsight Compute, roofline models, kernel launch overheads, and tail-latency analysis.

13

Empirical Research

Formulating hypotheses, setting up controlled baselines, reproducible benchmarking, and open problems.

# Session Commands

These are natural-language commands the learner can use.

## Start
Start today's lesson according to the skill and current curriculum.

## Assess
Assess my prerequisites before teaching the next topic.

## Source hunt
Find the strongest primary sources for this concept and give me exact reading targets.

## Read with me
Guide me through the specified paper/file without giving away the answer immediately.

## Socratic
Switch to Socratic mode.

## Production trace
Trace this concept through the current vLLM source.

## Source audit
Audit every important technical claim in the previous explanation.

## Implement
Give me the smallest educational implementation that exposes the mechanism.

## Debug
Use the debugging protocol and make me diagnose the issue.

## Benchmark
Design a reproducible benchmark.

## Review
Review my implementation like a senior inference engineer.

## Research
Switch to research mode and search related work before suggesting novelty.

## Independence
Give me only enough hints to continue independently.

## Progress
Update and summarize my mastery state.

## Teach back
Ask me to teach the concept back to you and grade the explanation.

# Source Registry

When starting a new topic, search in this order.

### vLLM
Official docs -> official repository -> current implementation -> tests -> benchmarks -> official engineering material.

### Transformer theory
Original papers -> authoritative framework docs/source -> educational material.

### GPU
NVIDIA documentation -> CUDA samples -> PyTorch/CUDA source -> kernel libraries -> community explanations.

### Distributed systems
NCCL docs -> PyTorch distributed docs/source -> original papers -> vLLM implementation.

### Research
Original paper -> authors' repository/project -> subsequent papers -> surveys -> secondary explanations.

The agent must add newly discovered canonical sources here when they become important to the curriculum.

Engineered for Systems Rigor

This dojo refuses passive summaries. It enforces active code inspection, turn-based probing, and hardware grounding.

Turn-Based Q&A

Asks one rigorous question at a time and stops. Evaluates your reasoning before offering minimal calibrated hints.

Source Governance

Grounded in primary code, official design RFCs, tests, and original papers over third-party summaries.

Production Tracing

Directs you to exact files, classes, and methods in upstream repositories before explaining mechanics.

Anti-Hallucination

Every claim is explicitly tagged as verified, inferred, hypothesis, historical, or unverified.

Flagship Curriculum: vllm-learning

Structured across 4 progressive tracks, from operating systems and GPU fundamentals to custom kernels and distributed scale.

Track 1: Foundations & Core Execution Stages 00–03
00

Systems Foundations

Linux processes, threading models, virtual memory, POSIX shared memory, and hardware profiling.

01

Deep Learning Execution

PyTorch tensor storage, strided layouts, CUDA device memory allocation, and autograd boundaries.

02

Transformer Inference

Causal masking, QKV projections, attention mechanisms, logits computation, and sampling math.

03

Prefill vs Decode Dynamics

Compute-bound prefill vs memory-bandwidth-bound autoregressive decode token generation.

Track 2: Memory & Batching Systems Stages 04–06
04

Continuous Batching

Dynamic token-budget scheduling, iteration-level admission, preemption, and queue management.

05

KV Cache & PagedAttention

Virtual memory paging applied to KV caches, block tables, prefix caching, and fragmentation control.

06

GPU Architecture & CUDA

Streaming Multiprocessors (SMs), warps, shared memory bank conflicts, and CUDA execution graphs.

Track 3: Kernels & Engine Internals Stages 07–09
07

Attention Kernels & Tiling

FlashAttention online softmax, SRAM tiling, fused operators, and IO-aware complexity.

08

Inference Engine Architecture

API ingress, request state, execution loop, model runner, samplers, and token streaming pipeline.

09

vLLM Production Mastery

Upstream code tracing of V0 vs V1 engines, worker architectures, custom ops, and test suites.

Track 4: Scale, Serving & Research Stages 10–13
10

Distributed Inference & NCCL

Tensor parallelism, all-reduce collective communication, pipeline bubbles, and expert parallelism.

11

Advanced Serving & Quantization

Chunked prefill, speculative decoding, disaggregated serving, FP8/AWQ/GPTQ weight quantization.

12

Performance Engineering

Nsight Systems, Nsight Compute, roofline models, kernel launch overheads, and tail-latency analysis.

13

Empirical Research

Formulating hypotheses, setting up controlled baselines, reproducible benchmarking, and open problems.
